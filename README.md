[View Live Website](https://a-j-cars.netlify.app/)

## 🛠️ Technologies Used

- HTML5
- CSS3

## ✨ Features

- Responsive layout for desktop, tablet, and mobile
- Navigation bar UI
- Hero section with background image
- Call-to-action buttons (UI only)

- Simple and clean design
